# digest-assets

Public images for Matt Finley's morning digest email (civic-roundtable repo, `03.16 Email drafter`).
Gmail can only show images at a public address, so they live here, served by GitHub Pages.

**Decorative images only.** Nothing with names, accounts, customers, or email content: this repository
and every file in it are public.

One folder per season, e.g. `2026-10-halloween/`. Addresses take the form
`https://matt-cr-deployments.github.io/digest-assets/<season>/<file>.png`.
